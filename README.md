# Construction Project Analysis

I am currently working as a Business Analyst Trainee at a PMC 
(Project Management Consultancy) company. In my work I deal 
with project data on a daily basis so I wanted to practice 
my SQL and Excel skills using similar kind of data.

I found a construction dataset on Kaggle that is similar 
to the kind of project data I work with in my current job 
as a Business Analyst.

## Tools
- MySQL Workbench
- Microsoft Excel

## What I did
- Cleaned the data in Excel first
- Imported it into MySQL and wrote queries to find useful patterns
- Built a dashboard in Excel to show the results visually

## What I found
- More than half the tasks (51%) are low risk
- Some tasks need a lot of labour and equipment at the same time
- High risk tasks with many dependencies can cause delays across the project
- Cost was almost the same across all risk levels which was surprising
- A few long duration tasks have very high constraint scores
